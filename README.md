# Café Meeples — a PLEXIS website concept

A three-page, mobile-first board-game café website: **The café**, **Play & what's on**, and **Visit**.

A typography-led game board, chance cards, numbered player cards, dated event filters, opening hours and a local Instagram enquiry composer. The interface uses plain text, printed borders and colour fields, without emoji, decorative icons or character artwork. No sign-in, build step, database or external JavaScript dependencies. Fonts are self-hosted.

## Editing

- `index.html`: café and coffee introduction.
- `play.html`: player cards and calendar.
- `visit.html`: address, hours and enquiry composer.
- `style.css`: shared visual design.
- `refresh.css`: compact mobile board, readable navigation and concise page layouts.
- `app.js`: optional interactions and dated event data.
- `assets/`: self-hosted fonts, a text favicon and one café photograph.

Serve the directory with any static web server. GitHub Pages serves `main` from the repository root. All internal links are relative and work under a repository subpath.

## Research and content

Business identity, address, hours and the October 2026 programme were checked against [Café Meeples' official Instagram](https://www.instagram.com/cafe_meeples/) on 18 October 2026. Sources: [opening hours](https://www.instagram.com/cafe_meeples/p/Dc5GzU9xenp/), [October line-up](https://www.instagram.com/cafe_meeples/p/Dd7O908E3kX/), and [Tabletop SL event description](https://www.tabletopsl.com/events/board-gaming-night-7). That last event has ended; it is a research source, not a live reservation link.

The photograph `assets/playing.jpg` is a thumbnail from the café's [10 October reel](https://www.instagram.com/cafe_meeples/reel/DeTzAclJ4zy/), used as venue reference in this independent client concept. Original photography remains its owner's property. Fonts are distributed under their included SIL Open Font Licenses. The printed board layout is original typography and CSS.

## Before client launch

Confirm the current menu, game fees, booking contact, holiday hours and photo permissions with the café. Keep the dated event roster current; past dates expire automatically using Colombo's local date. Tabletop SL is an event collaborator, and its collection size, age rules and pricing are not presented as café policies.

The form prepares a message locally. It sends nothing automatically and does not reserve a table. No personal information is stored or transmitted by this website. The visitor chooses whether to copy and send their enquiry through Instagram.

This is an independent PLEXIS concept for review, not an official Café Meeples booking service.
